## Состояние

Единственный источник правды — глобальный `gameState`, созданный
`freshState()`. Ничего важного не живёт в мутированных объектах комнат:
мир целиком восстанавливается из флагов, поэтому загрузка сейва даёт ровно ту
же картину, что была до сохранения.

```js
gameState = {
  currentRoom, playerX, playerY, act, chapter, eventStep,
  flags:    { ... },   // 123 булевых флага истории
  counters: { ... },   // 17 счётчиков (uniDay, campusHeat, runesDisarmed, ...)
  stats:    { trustSue, witchAmbition, humanity, hellAffinity },
  inventory: [], scenesSeen: [], journal: [], memories: [], settings: {}
}
```

Хелперы: `F('flag')`, `setFlag('flag', v)`, `C('counter')`, `setCounter`,
`addC`, `S('stat')`, `addStats({...})`, `hasItem`.

`localStorage`, три ключа:

```
revenge_of_witch_save_v2        текущее сохранение
revenge_of_witch_checkpoint_v2  последний важный выбор (кнопка «вернуться»)
revenge_of_witch_meta_v2        открытые концовки и воспоминания, переживает сброс
```

## Комната

```js
roomKey: {
  name, music, w, h,
  zone,                       // 'indoor' | 'street' | 'town' — фоновый эмбиент
  weather: { rain, fog, wind, leaves, indoor },
  light: { tint, dark },
  lights: [ {x,y,r,c,i}, ... ],       // источники света
  cinematic: true,                    // необязательно: игрок не управляет
  bgPaint(ctx) { ... },               // фон рисуется кодом
  overPaint(ctx) { ... },             // необязательно: поверх всего (руны, туман)
  objects: [ { t:'ключ_пропса', x, y }, ... ],
  walls:   [ {x,y,w,h}, ... ],
  interactables: [ ... ],
  npcs: [ ... ],
  spawn: { имя:[x,y], default:[x,y] }, // необязательные точки входа
  onEnter() { ... },                  // вызывается при каждом входе
}
```

**Интерактив.** Прямоугольник, к центру которого игрок должен подойти ближе
чем на 30 пикселей (считается от точки `Player.x, Player.y - 8`).

```js
{ x, y, w, h, name:'toWest', prompt:'Западное крыло',
  when: ()=> F('someFlag'),          // необязательно: когда существует
  action: async ()=> await changeRoom('uniWestHall', 130, 560) }
```

**NPC.** Патрулирующие персонажи не блокируют движение — их можно обойти.

```js
{ x, y, sprite:'sue', name:'Сью',
  speed: .34, path:[[x,y],[x,y],...], pause: 0,
  when: ()=> F('uniArrived') && !F('premiereDone'),
  dialogue: ()=> Scene.play('sueRehearsalTalk') }
```

## Пропсы

```js
Art.def('stairs_main',
        { w:96, h:64, ax:48, ay:60, foot:{x:-48,y:-60,w:96,h:62} },
        g => { /* рисование в offscreen-канвас */ });
```

* `ax, ay` — точка касания пола внутри картинки. Объект ставится в комнате
  координатой этой точки, а не левого верхнего угла.
* `foot` — прямоугольник столкновения **в координатах относительно `x, y`
  объекта**. Пропс без `foot` — чистая декорация, сквозь неё ходят.
* Флаги мета: `solid`, `tall`, `light`, `flat` (рисуется в слое пола),
  `wall` (рисуется в слое стены, до сортировки по глубине).

Ошибка в `foot` — самый частый источник непроходимости: см. раздел граблей в
`HANDOFF.md`.

## Отрисовка

Три прохода в `drawRoom()`:

1. `bgPaint` комнаты и пропсы с флагом `flat` — декали пола;
2. пропсы с флагом `wall` — всё, что висит на стене;
3. остальные пропсы, NPC и игрок — **сортируются по видимой базе**
   `o.y + (meta.h - meta.ay)`, поэтому персонаж корректно проходит за мебелью
   и перед ней.

Затем свет (`Lighting`), погода (`Weather`), эффекты (`FX`), `overPaint`.

`World.invalidate()` сбрасывает кэш фона — вызывать после любого изменения
состава комнаты.

## Композиторы коридоров

Университетские коридоры собираются не вручную, а раскладкой:

```js
const UNI_C2_WALL = wallLayout(680, [           // по X — горизонтальный коридор
  { k:'door', label:'201', w:40, id:'a201', style:'shut' },
  { k:'win',  id:'w0', w:50 },
  ...
]);
UNI_C2_WALL.at('a201')      // левый край проёма
UNI_C2_WALL.mid('a201')     // середина проёма
UNI_C2_WALL.pierMid(1)      // середина простенка №1 — куда вешать картины
```

`wingLayout(H, items)` — то же самое по Y для вертикальных крыльев,
`.stand(id, W, side)` даёт точку, где встать перед дверью.

Рисуют это `paintCorridor(ctx, W, H, o)` и `paintWing(ctx, W, H, o)`: пол,
толстые стены, ниши дверей в толщине стены, таблички на простенках, оконные
ниши с косыми пятнами света. `paintRoom` — комната с проёмом в боковой стене.
`DOOR_SKIN` задаёт вид двери: `shut`, `glass`, `heavy` и другие.

**Важно:** простенок обычно уже, чем крупный пропс. В коридоре второго этажа,
например, самый широкий простенок — 59 пикселей, а марш лестницы — 96: марш не
помещается ни в один и неизбежно перекрывает какой-то проём. Ставить широкую
мебель вплотную к стене с дверями нельзя — надо либо отодвигать её от стены,
либо выбирать проём, который не жалко (декоративная дверь, а не сюжетная).
Проверяет `tests/reach.js`: он считает мебель геометрией уровня и валит
прогон, если до интерактива не дойти ногами.

## Движок сцен

`Scripts` — объект из 125 массивов команд. `Scene.play('имя')` проигрывает.

```js
имяСцены: [
  { music:'tense' },
  { dlg:[ {who:'naya', expr:'shocked', text:'...'}, ... ] },
  { flag:'archiveFolderFound' },
  ()=>{ Journal.add('folderFound'); },          // голая функция исполняется
  ()=>{ return { goto:'другаяСцена' }; },        // и может передать управление
  { stats:{ witchAmbition:+4 } },
]
```

Команды: `dlg`, `room`, `flag`, `act`, `goto`, `jump`, `wait`, `title`,
`chapter`, `checkpoint`, `stats`, `memory`, `item`, `removeItem`, `music`,
`duck`, `sfx`, `fadeIn`, `fadeOut`, `flash`, `glitch`, `shake`, `magic`, `fx`,
`cast`, `uncast`, `castWalk`, `zoom`, `shift`, `swing`, `spark`, `creature`,
`ending`, `montage` и несколько сценоспецифичных (`medeaFall`, `witchTableau`,
`lilithFig`, `crackStar`, `butterfly`, `stones`).

**`{action(){}}` командой сцены не является.** `action` валиден только внутри
массива реплик диалога.

**Повторное проигрывание.** `Scene.play` смотрит в `gameState.scenesSeen`: уже
виденная сцена вместо повтора отдаёт `Recap.show(name)` — короткий пересказ с
напоминанием текущей цели. Исключение — 22 имени в `Scene.DISPATCHERS`: это
диспетчеры и ежедневные сцены, они обязаны отыгрываться каждый раз. Переход
через `goto` внутри сцены никогда не блокируется.

**Обрыв.** У сцен есть поколение (`Scene.epoch`). `Scene.abort()` его меняет,
и все шаги старого поколения молча выходят из `_runList`, а `play().then()` не
доводит сцену до конца. Без этого оборванная сцена продолжает менять комнаты и
гасить экран поверх нового состояния. `abort()` вызывается из `beginPlay()`
(новая игра, загрузка, перемотка) и из `DevTools`.

## Цели и журнал

`Quests.GOALS` — список от позднего к раннему, выигрывает **первое**
совпадение. Поэтому порядок в списке — это приоритет.

```js
{ w: ()=> C('uniDay') === 4 && F('libMissing') && F('sawBasement'),
  t: 'Найти в цокольном архиве пропавшую папку.',
  s: 'Коробки без описи.' }              // s может быть и функцией — Quests.sub(g)
```

`Journal.FACTS` — реестр фактов по ключам, `{ d: день, t: текст, main }`.
Журнал отвечает на «что я уже знаю», цель — на «что делать сейчас».

`UniDay` — четыре дня главы: `TODO` по дням, `ready(d)` (все дела дня
закрыты), `left(d)`, `advance()`. При переходе на новый день сбрасываются
флаги «была там сегодня» и, для дней 2–3, смена в кафе.

## Мини-игра смены

`Shift` — официантка: гость садится, над столом всплывает заказ, Ная идёт к
гостю, принимает, бежит к Крису, выбирает блюдо из меню, Крис готовит три
секунды и ставит на стойку, Ная относит. Сложность — не перепутать, кто что
заказал. Играется на отдельном канвасе `#shiftCanvas`, вся логика
взаимодействия построена на `contacts()` — что находится рядом с тем местом,
куда Ная дошла.

Цикл устроен так, чтобы смена **всегда** завершалась: кадр планируется до
отрисовки, `update`/`draw` обёрнуты в `try/catch`.

## Меню разработчика

`DevTools`: открывается кнопкой в главном меню, кнопкой в паузе и клавишей
`F8`, закрывается `Escape`. Три блока — 16 сюжетных точек главы, две сетки
быстрого перехода (университет и остальной мир, кнопки строятся из `Rooms`,
поэтому новая комната появляется сама) и общие тесты.

`normalize()` достраивает цепочку флагов вниз по дню, чтобы цель и журнал
соответствовали выбранному моменту. `ensureRunning()` поднимает игровой цикл,
если прыгнули из главного меню. `freeSpot()` ищет свободное место от центра
комнаты наружу.
