# Чтение нот со скана

Тем, которые делаются по нотам, нужен вход. MusicXML и MIDI читаются
сами; PDF со сканом — нет, там просто картинки. Этими скриптами читали
прелюдию Глиэра, соч. 43 № 1, из которой сделана тема университета.

Порядок:

```sh
python3 pages.py                     # страницы PDF -> score/p1.png …
python3 crop.py p1.png sys1.png 150 260 1160 230 2     # вырезать систему
python3 omr3.py p1.png 200 1250 270 500                # найти головки -> heads.json
python3 pitch.py                                       # координаты -> высоты
```

* `pages.py` — скан нарезан на горизонтальные полосы, разложенные по
  странице матрицами `cm … Do`. Скрипт собирает их обратно: без этого
  страница выходит перемешанной.
* `omr_lib.py` — чтение и запись PNG без зависимостей: в окружении нет
  ни Pillow, ни poppler.
* `omr3.py` — снимает тонкие горизонтальные линии (стан и добавочные) и
  ищет головки шаблоном 11×6 с подавлением немаксимумов. Балка от
  головки отличается тем, что сплошная полоса вокруг неё гораздо шире.
* `pitch.py` — переводит координату в высоту: позиции линеек задают
  ступень, ключ — начало отсчёта, знаки при ключе — альтерацию.

Что это даёт и чего не даёт. Даёт гармонию по тактам и контур мелодии —
достаточно, чтобы собрать переложение, которое узнаётся. Не даёт
партитуры: случайные знаки, внутренние голоса и ритм внутри группы
остаются за кадром, их дочитывают глазами по увеличенной картинке.

Правовая сторона: переносить можно общественное достояние, народное или
своё. Глиэр умер в 1956, опус 43 издан в 1907.
