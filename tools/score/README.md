# Ноты → партитура движка

## Коротко: берите MIDI

```sh
python3 midi.py путь/к/файлу.midi      # разбор -> gliere.json
python3 midi2track.py                  # выбранные такты -> партитура
```

`midi.py` читает стандартный MIDI: дорожки, темп, размер, знаки при
ключе, ноты с длительностями. `midi2track.py` берёт из него окно тактов
(`FIRST`, `LAST`) и печатает готовый кусок для `Music.TRACKS`:

* **ноты** переносятся один в один, доли считаются от начала петли,
  длительности округляются до четверти доли — сетка движка всё равно
  восьмые;
* **аккорды** выводятся из самих нот: на каждый такт перебираются
  созвучия и берётся первое, все ступени которого в этом такте реально
  звучат. Если не подходит ни одно — а на хроматике так и бывает —
  ставится один основной тон (`Gb1`), потому что подложка, которая не
  может спорить с линией, лучше выдуманного трезвучия.

Ничего не досочиняется. Расхождение с исходником проверяется отдельно:
тема читается из собранной игры и сверяется с MIDI нота в ноту.

## Скан PDF читается, но верить ему нельзя

```sh
python3 pages.py                                    # PDF -> score/p1.png …
python3 crop.py p1.png sys1.png 150 260 1160 230 2  # вырезать систему
python3 omr3.py p1.png 200 1250 270 500             # головки -> heads.json
python3 pitch.py                                    # координаты -> высоты
```

* `pages.py` — скан нарезан на горизонтальные полосы, разложенные по
  странице матрицами `cm … Do`. Без сборки по матрицам страница выходит
  перемешанной.
* `omr_lib.py` — чтение и запись PNG без зависимостей: в окружении нет
  ни Pillow, ни poppler.
* `omr3.py` — снимает тонкие горизонтальные линии (стан и добавочные) и
  ищет головки шаблоном 11×6 с подавлением немаксимумов. Балка от
  головки отличается тем, что сплошная полоса вокруг неё гораздо шире.
* `pitch.py` — позиция линейки задаёт ступень, ключ — начало отсчёта,
  знаки при ключе — альтерацию.

**Чем это кончилось на прелюдии Глиэра.** Распознавание нашло около двух
третей головок, снятые высоты все оказались диатоническими — выглядело
убедительно. И было неверным: первый такт прочитался как доминанта
вместо тоники, дальше гармония разошлась, и тема зазвучала фальшиво.
Ошибку слышно, а по картинке не видно.

Поэтому: скан годится, чтобы снять размер, темп, тональность и форму.
Ноты берите из MIDI.
